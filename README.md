# Ethra.hr

[Открыть демонстрационный сайт](https://ethra-hr-demo.kolyaselekh.workers.dev/)

Интерактивный демосайт карьерных и управленческих консультаций в эстетике cinema noir.

## Что включено

- Главная страница с бархатным занавесом. Шторы автоматически открываются через **3 секунды** после загрузки сайта либо сразу после нажатия на логотип.
- Каталог услуг с тематическими направлениями и переходами между связанными продуктами. Буквенные метки А, Б, В, Г и т. д. убраны из «Наших направлений».
- Календарь, тестовая предоплата 50%, демонстрационные записи и админка.
- Дизайн адаптирован для мобильных экранов.

## Локально

Скачайте `index.html` и откройте в браузере. Графические материалы встроены в HTML.

## Важно

Это **демонстрационный прототип**, а не готовая система онлайн-записи: платежи имитируются, сведения о тестовых записях сохраняются локально в браузере, реальные уведомления Telegram/WhatsApp и Google Calendar не подключены.

## Размещение

Демоверсия размещена на Cloudflare Workers: `https://ethra-hr-demo.kolyaselekh.workers.dev/`. Worker отдаёт публичный HTML из этого репозитория с кратковременным кэшированием; изменения в `index.html` отражаются после обновления кэша.
