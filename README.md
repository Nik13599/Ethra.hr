# Ethra.hr

Демонстрационный сайт карьерных и управленческих консультаций в стиле cinema noir.

Это демоверсия: платежи симулируются, реальная запись, Google Calendar и мессенджер-уведомления не подключены.

Для локального запуска откройте `index.html` в браузере. Для публикации используется статический хостинг.
